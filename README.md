## About

<img align="right" width="380" src="https://github-readme-stats.vercel.app/api?username=AlfredBateman&show_icons=true&theme=tokyonight&hide_border=true&bg_color=0d1117&title_color=a78bfa&icon_color=8b5cf6&text_color=c9d1d9&include_all_commits=true&count_private=true&hide_title=true"/>

I am a final-year **Computer Science Engineering** undergraduate at Chitkara University who builds, tests, and deploys **full-stack and AI-powered applications** with Python, TypeScript, and Next.js.

My engineering focus is **correctness under uncertainty**: automated testing, CI/CD, and validating LLM output before it reaches a user. My flagship project, **AgentProbe**, detects regressions in LLM agents using repeated runs and exact statistical tests instead of single-run checks — cutting false regression alarms on unchanged flaky agents from **70.6% to 0.9%** in simulation.

I approach every project with a **product engineering mindset**: ship a working end-to-end system, make it fail safely, measure it honestly, and document its limits.

**Open To**

- Entry-level Backend Engineering roles
- Entry-level Full Stack Engineering roles
- Entry-level AI / LLM Engineering roles
- Open source collaboration on testing, evaluation, and developer tooling

 |
| **Scale** | Every case run 10 times; 10 rule-based judges plus LLM-rubric and consistency judges |
| **Performance** | False regression alarms on unchanged flaky agents reduced from 70.6% to 0.9% in simulation versus a single-run check |
| **Security** | SSRF guard on HTTP, MCP, and Python agent adapters |
| **Impact** | GitHub Action comments on pull requests and fails the check on a detected regression |
| **Repository** | [github.com/AlfredBateman/AgentProbe](https://github.com/AlfredBateman/AgentProbe) |

AgentProbe treats agent behaviour as a distribution rather than a single sample. Verdicts use a per-case Fisher exact test with Tarone–Holm correction and a paired sign-flip permutation test, computed in exact rational arithmetic to avoid floating-point drift. The system ships as a FastAPI and PostgreSQL backend, a Next.js dashboard, a Typer CLI, and a GitHub Action. It is verified by 1,145 Python tests, 184 web unit tests, and 14 end-to-end specs (97% coverage on core and API), with a fully automated CI-to-deploy pipeline on Vercel, Render, and Neon.
